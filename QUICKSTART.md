# Quick Start

## Install

```bash
pip install -r requirements.txt
```

## Run on macOS

```bash
python3 VIRTUALDJ_LYRICS_IA_FIX_v4_1.py
```

## Run on Windows

```bash
python VIRTUALDJ_LYRICS_IA_FIX_v4_1.py
```

Then open, if needed:

```text
http://127.0.0.1:5055
```

## Before publishing

Make sure your folder contains:

```text
VIRTUALDJ_LYRICS_IA_FIX_v4_1.py
README.md
LICENSE
requirements.txt
.gitignore
CHANGELOG.md
QUICKSTART.md
```
